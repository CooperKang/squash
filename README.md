# 스쿼시 코트

스쿼시를 처음 시작하는 사람을 위한 안내 웹앱입니다. <https://cooperkang.github.io/squash/>

- **스쿼시란 / 경기 규칙**: 코트 그림을 눌러 보며 익히는 선 이름, PAR 11 점수, 서브, 렛·스트로크
- **ㄱ자 게임**: 동호회에서 여럿이 돌아가며 치는 3/4 코트 게임. 바닥을 눌러 실점 구역을 확인하고, 이긴 사람·대기 줄이 바뀌는 순서를 돌려 봐요
- **기술 백과**: 드라이브·로브·드롭·킬부터 보스트, 3벽·스키드·리버스 보스트, 백월 샷(뒷벽치기), 서브까지 게임과 같은 물리로 굴린 3D 그림(끌어서 회전, 높이 막대, 포핸드·백핸드 전환)으로 보여 주고, 『스쿼시론』의 장 구성을 따른 용어 사전을 붙였어요
- **혼자 연습**: 운동 전 동적 스트레칭 / 연습 방법 / 운동 후 스트레칭·폼롤러 / 수준별 팁·루틴을 탭으로. 연습마다 공이 이어지는 길을 3D로(포핸드·백핸드 전환), 스트레칭마다 움직이는 막대 인형 그림(늘어나는 곳은 청록색, 지금 동작의 설명을 강조), 따라 하기 타이머와 유튜브 영상
- **장비**: 라켓 무게·밸런스·헤드 모양, 브랜드별 성향, 공의 점 색깔, 세계 랭커들이 쓰는 라켓 브랜드
- **라켓 찾기**: 질문 네 개로 영산스포츠(ysretail.com) 판매 라켓 중에서 추천하고 구매 페이지로 연결
- **대회 현황판**: PSA 월드 투어 일정, 최근 경기 결과(하이라이트 영상이 있으면 바로 재생), 세계 랭킹, 대한스쿼시연맹 국내 대회와 랭킹
- **코트 찾기**: 전국 스쿼시장의 코트 수·연락처를 지역·검색·내 주변으로 찾기. 연맹 공인(정식 규격) 코트, 복식·유리 코트, 학교·회사·아파트 전용으로 보이는 곳을 구분
- **터치 스쿼시**: 날아오는 공을 마우스나 손가락으로 눌러 치는 미니 게임(PAR 11, 난이도 3단계). 누른 곳을 라켓이 공을 때린 곳으로 보고(벽 반대쪽은 보스트, 가운데 드라이브, 벽 쪽 크로스, 윗면 드롭·킬, 아랫면 로브) 샷 계획기가 실제 물리로 '제대로 들어가는' 공을 찾아요. 상대는 공이 올 곳과 시각을 미리 계산해 스플릿 스텝, 이동, 런지, 백스윙, 팔로스루까지 관절(IK)로 움직여요(`src/game/cpuBody.ts`). 쉬움 모드는 링이 보일 때 누르면 멈추고 공을 크게 보여 칸마다 적힌 샷을 고르게 하고, PC 커서 라켓은 포핸드·백핸드 쪽으로 기울고 칠 때마다 라켓을 휘둘러요. 그리고 점수가 날 때 관련 규칙을 물어보고 원하면 보여 줘요. 듀스와 게임볼도 알려 줘요
- **현실모드**: 공을 누르면 잠깐 멈춰 파워를 정하고 놓아서 쳐요. 이동·강타·T존 점유에 따른 체력을 나와 봇 모두에게 적용하며, 공 추적과 T 복귀는 자동이에요. 미니 코트에서 움직임을 보고 첫 진입 조작 안내를 확인할 수 있어요. [조작·체력 모델과 검증](docs/realism-mode.md)

디자인은 Harrow Response 115 라켓의 색(실버 프레임, 딥 틸, 검정 링, 흰 그립)에서 가져왔습니다.

## 개발

```sh
npm install
npm run dev      # http://localhost:5173
npm test
npm run data     # 현황판 데이터를 public/data/에 새로 받기
npm run courts   # 코트 목록을 public/data/courts.json에 새로 받기(새 센터만 상세 요청)
npm run build
```

## 검색엔진과 AI

`npm run build`는 앱을 빌드한 뒤 `src/entry-server.tsx`로 화면마다 HTML을 미리 그려 `dist/rules/index.html` 같은 정적 페이지를 만든다(`scripts/prerender.mjs`). 자바스크립트를 잘 돌리지 않는 검색엔진(네이버 등)과 AI 크롤러도 본문을 읽고, 주소마다 제목·설명·미리보기 이미지(`public/og.png`)·구조화 데이터가 붙는다. 브라우저로 열면 `main.tsx`가 앱 주소(`#/rules`)로 바꾼다.

- 페이지 목록과 제목·설명: `src/seo.ts`
- 지역별 스쿼시장 정적 페이지: `/squash/courts/seoul/` 등
- `sitemap.xml`, `llms.txt`(목차), `llms-full.txt`(본문 전체)
- 도메인 루트의 `robots.txt`는 허브 저장소에 있다

## 데이터

| 파일 | 출처 | 갱신 |
|---|---|---|
| `public/data/calendar.json` | PSA 투어 사이트의 WordPress REST API | GitHub Actions가 3시간마다 |
| `public/data/results.json` | PSA 결과 API(최근 1주일치) | 3시간마다 + 화면을 열 때 브라우저에서 한 번 더 |
| `public/data/rankings.json` | PSA 랭킹 API | 3시간마다 |
| `public/data/videos.json` | PSA 공식 유튜브(SQUASHTV) 채널 RSS(최근 15개) | 3시간마다 |
| `public/data/korea.json` | 대한스쿼시연맹(koreasquash.or.kr) 대회 일정·랭킹 | 3시간마다 |
| `public/data/courts.json` | [스쿼시 센터(코트) 안내](https://www.squash.pe.kr/)(목록·좌표·코트 수·전화) + 대한스쿼시연맹 공인 코트 현황. 샤워·주차 등 시설과 수용 인원은 출처에 없어 비워 둠 | 수동(`npm run courts`). 출처가 GitHub Actions 서버의 접속을 막아(403) 자동 갱신에서 뺌 |
| `src/data/rackets.ts` | 영산스포츠 스쿼시 라켓 목록 | 손으로(판매처 robots.txt가 자동 수집을 막아 둠) |

빌드마다 git 커밋 해시를 `version.json`과 코드(`__BUILD_ID__`)에 넣습니다. 화면은 처음 열 때·다시 보일 때·10분마다 이 파일을 비교해 새 배포가 있으면 위쪽 가운데에 새로고침 뱃지를 띄웁니다(`src/update.ts`; ETag로 바뀐 게 없으면 304, 1분 안의 재확인은 생략).

수집 스크립트는 `scripts/fetch-data.mjs`입니다. 매번 출처가 지금 주는 것만 쓰고 지난 데이터와 합치지 않습니다. 출처 하나가 실패하면 지금 배포된 파일을 그대로 씁니다. 화면은 7일 넘게 갱신되지 않은 파일을 보여주지 않고 "업데이트가 멈췄어요"라고 알립니다(수집이 깨졌거나, 저장소에 60일 동안 커밋이 없어 GitHub가 예약 실행을 꺼 버린 경우).
GitHub는 저장소에 60일 동안 활동이 없으면 예약 실행을 멈추니, 멈췄다면 Actions 탭에서 다시 켜 주세요.

## 라켓 목록 고치기

`src/data/rackets.ts`의 항목을 직접 고칩니다. `style`(파워/컨트롤/스피드/올라운드)과 `level`은 제조사 라인별 일반적인 성격으로 붙인 참고값이고, 추천 점수는 `src/data/recommend.ts`에서 계산합니다.
